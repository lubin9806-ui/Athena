# Athena Offline Pack

This folder contains the Athena installer, the Ollama installer candidate, and
only the allowlisted Ollama files required for `qwen2.5:14b`.

## Install

Double-click `START_HERE.bat`.

The script will:

1. install Ollama if it is not already installed
2. copy the allowlisted model files into `%USERPROFILE%\.ollama\models`
3. start Ollama
4. verify that `qwen2.5:14b` is available
5. run the Athena installer
6. launch Athena when the default install path is found

## Notes

- The model files are large, so copying can take several minutes.
- Existing Ollama models are preserved.
- Athena expects Ollama at `http://127.0.0.1:11434` and the default model `qwen2.5:14b`.
- If Windows blocks the scripts, right-click `START_HERE.bat`, choose Properties, and unblock it.

## Supply-chain boundary

The offline pack is generated by `npm.cmd run package:offline`. It requires
`docs/OFFLINE_MODEL_ALLOWLIST.json` and refuses to build if any listed file is
missing or its SHA-256 does not match.

The current allowlist records:

- model: `qwen2.5:14b`
- Ollama model ID: `7cdf5a0187d5`
- quantization: `Q4_K_M`
- upstream reference: `Qwen/Qwen2.5-14B-Instruct`
- license: Apache-2.0
- main model blob SHA-256:
  `2049F5674B1E92B4464E5729975C9689FCFBF0B0E4443CCF10B5339F370F9A54`

Copying the whole user `.ollama\models` directory is not allowed.
Public redistribution remains Blocked until Ollama installer redistribution,
Qwen model notice handling, publisher identity, EULA/privacy URL, and
asset/trademark signoffs are complete.
