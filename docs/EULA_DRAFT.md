## 冻结的产品条款

用户获得一份不可转售、非独占的 Athena Desktop 1.x Personal 个人使用许可，最多同时激活 2 台本人控制的 Windows 设备。许可为一次性购买，不包含订阅、云服务额度、2.0 升级、组织席位或跨平台版本。正常换机需停用旧设备；无法访问旧设备时按支持流程申请重置。

软件依赖用户自行选择和许可的 Ollama 与模型。用户负责确认输入、输出和自动化操作符合当地法律及第三方权利。AI 输出可能不准确；涉及医疗、法律、财务、安全或其他高风险事项时不得把输出作为唯一依据。

Execute 是默认关闭的 Beta 能力。用户启用后仍需检查文件、命令、程序和网络目标；软件中的确认、停止、权限和日志机制不构成结果保证。禁止利用软件实施恶意访问、凭据窃取、破坏、监控他人或其他违法活动。

退款按 `DESKTOP_1_0_COMMERCIAL_POLICY.md` 的 14 日自愿退款边界和适用法定权利处理。退款撤销软件 entitlement，但不远程删除本机数据。用户可以在隐私与数据中心导出或清除支持范围内的本机数据。
