# Athena 第一笔收入私测计划

> 状态：收入验证 / 私测招募，不代表 Desktop 1.0 正式发布通过。  
> 日期：2026-08-09。  
> 渠道：抖音短视频 + 抖音私信 + 微信跟进。  
> 价格：19 元早鸟陪伴席位。

本文用于帮助 Athena 在不伪装正式发布的前提下，拿到第一笔真实用户付款。本文不关闭 `ATH-REL-001`、`ATH-DESKTOP-001`、`ATH-DESKTOP-002` 或 `ATH-OPS-001`。

## 1. 产品定位

Athena 是一款面向 Windows 用户的本地优先 AI 桌面伙伴，定位是：

> 情感陪伴 + AI 工具。

一句话卖点：

> 一个能陪你写作、思考、整理事情的桌面 AI 伙伴。

抖音和私信用这句话：

> Athena 不是单纯的聊天框，而是一个放在电脑旁边的 AI 伙伴：能陪你说话，也能帮你写东西、理思路、做计划。

不要宣称：

- 已正式发布
- 已通过商店审核
- 安装零风险
- Windows 不会弹未知发布者提示
- 已支持云同步
- 已支持手机端
- 有治疗、诊断或危机干预能力
- 可以替代真人关系或专业心理服务

## 2. 第一批用户

先只找一种人：

> 经常一个人学习、工作、创作，既需要情绪陪伴，也需要 AI 帮忙整理思路的人。

优先用户：

- 独立创作者：需要选题、文案、陪伴式写作
- 学生：需要学习计划、笔记整理、情绪支持
- 自由职业者：长时间独自工作，需要一个稳定的思考伙伴
- AI 重度用户：已经会用 AI，但觉得网页聊天框太冷

暂不优先：

- 企业采购用户
- 需要发票、合同、SLA 的用户
- 未成年人单独购买
- 明确寻求心理治疗、诊断、危机干预的人
- 不能接受早期产品不稳定的人

## 3. 19 元早鸟席位

名称：

> Athena 19 元早鸟陪伴席位。

用户现在得到：

- 进入 Athena 第一批私测名单
- 通过微信获得人工跟进
- 获得使用指导和上手陪跑
- 当受控 Windows 私测包允许交付时，优先获得体验资格
- 可以影响 Athena 的陪伴风格和工具功能方向

用户现在没有得到：

- Desktop 1.0 正式许可证
- 应用商店交付
- 已签名公开安装包承诺
- 云同步
- 手机端
- 医疗、治疗、危机干预或确定性情绪效果承诺

退款边界：

> 如果用户支付 19 元后不适合进入第一批私测，默认退款；只有用户明确同意时，才保留为后续体验抵扣。

这 19 元是早鸟陪伴席位 / 上手陪跑费用，不是正式 Desktop 1.0 软件销售。

## 6. 私测收集表

每个感兴趣的人都问：

1. 你最想让 Athena 帮你什么：陪伴、写作、计划、学习、文件/工作整理，还是别的？
2. 你用的是 Windows 10 还是 Windows 11？
3. 你是否理解它现在是早期受控私测，不是正式公开版？
4. 你是否愿意通过微信做上手和反馈？
5. 如果安装交付因为签名或安全门延迟，你希望退款，还是保留为后续体验抵扣？

优先接受：

- 能讲清楚一个具体使用场景的人
- 能接受早期产品边界的人
- 愿意反馈的人
- 不是来寻求医疗、治疗、危机干预的人

延期或拒绝：

- 要求稳定正式版的人
- 要求公司采购、发票、合同或 SLA 的人
- 未成年人单独购买
- 主要诉求是心理治疗、诊断或紧急帮助的人

## 7. 交付模式

模式 A：暂时没有签名安装包

- 抖音收集兴趣
- 微信继续沟通
- 用户接受边界后再收 19 元
- 交付演示、上手指导、使用规划和私测优先资格
- 不把未签名安装包作为公开下载发给陌生流量

模式 B：受控签名私测包可用

- `release:preflight` 通过
- 从干净工作区构建签名候选包
- 完成候选包验证和安装 smoke
- 只发给已筛选私测用户
- 记录 Windows 版本、安装结果、首轮体验和退款状态

模式 C：公开发布

- 当前不允许。必须等发布、运维、支持、隐私、签名、更新和商业门关闭。
