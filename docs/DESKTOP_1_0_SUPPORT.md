# Athena Desktop 1.0 支持与联系渠道运行稿

> 窗口 07 预发布文档。所有外部地址均由 `config/commercial.json` 提供；当前值为 `null`，因此本稿不能作为已经开放的支持服务。

## 入口与分流

正式官网和应用内只展示三个入口：一般支持、隐私、安全。支付平台的交易编号可以作为工单字段，但不得要求用户提交完整许可证密钥、密码、聊天正文、记忆内容、Authorization/Cookie 或无关文件。

一般支持覆盖安装、Ollama/模型连接、激活、停用、丢失设备重置、退款和产品故障。隐私入口覆盖数据地图、联网同意、导出/清除和数据权利。安全入口覆盖可利用漏洞、恶意更新、签名异常、敏感信息暴露和 Execute 越权。

## 最小工单字段

- 联系邮箱、购买/候选编号、Athena 版本和 Windows 版本；
- 问题类型、发生时间、复现步骤和用户主动附上的脱敏日志；
- 激活问题只收 entitlement ID 后 8 位与设备槽位状态，不收完整许可证密钥；
- 隐私/安全报告允许匿名或化名提交，具体法律身份要求待销售区域确定后复核。

## 响应目标

一般支持首次响应目标为 2 个工作日；隐私请求为 5 个工作日；安全报告为 1 个工作日确认收到。它们是运营目标，不是当前已提供的 SLA。P0 安全、数据损坏、签名或更新异常需立即转入发布暂停/撤包链；该跨平台事件机制由 ATH-OPS-001 / 窗口 11 最终冻结。

## 已知限制页

正式已知限制页至少列出：仅 Windows 10/11 x64、需要用户自备 Ollama/模型、SQLite 当前明文、Execute 为默认关闭的 Beta、联网语音/搜索不是“完全离线”、未支持 Live2D/日历/跨平台/云同步，以及安装签名和真实 Beta 的当前状态。页面未获得稳定 URL 前不得勾选发布清单中的“已知问题页可用”。
