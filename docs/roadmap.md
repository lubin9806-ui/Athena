# Legacy Vision Roadmap

> 状态：历史愿景快照，**不是发布承诺**。商业版本、平台范围和优先级只以 `COMMERCIAL_ROADMAP.md` 与 `PRODUCT_MATRIX.md` 为准。

## 已有可运行基础

- Electron Windows 桌面壳、本地 Ollama 对话和 SQLite 记忆。
- Create、Companion、Reason、Execute 四模式。
- 联网搜索研究、语音原型、主题与记忆管理界面。
- 文件、终端、程序和网络电脑工具原型。

这些能力仍可能存在安全、隐私、依赖、许可或发布阻断；“已实现”不等于“可商业发布”。

## 仍属愿景或不完整能力

- Live2D 角色、完整插件生态、音乐/日历/天气集成。
- 持久化提醒和完整工作流自动化。
- Steamworks、Mobile、Cloud、跨设备同步、账号、订阅和商业授权。
- macOS、Linux 和 Steam Deck 支持。

任何愿景进入正式计划前，必须先在 `PRODUCT_MATRIX.md` 定义平台边界，在 `ISSUE_REGISTER.md` 建立负责窗口和验收条件，再由对应窗口实现。
