# Athena Desktop 1.0 正式发行文案源稿

> 状态：Prelaunch / 尚未开放购买。该文案只定义可用素材边界，不代表已经通过发布门。价格、公司主体、域名、支持地址、正式截图和下载链接均待定。

## 商店短描述

Athena 是面向 Windows 10/11 x64 的本地优先 AI 桌面助手，使用你自己的 Ollama 模型，提供三种对话模式、可管理的本机记忆和可选的受控电脑操作。

## 商店长描述

Athena 把日常对话、创作思考和严谨分析放进一个 Windows 桌面应用。Create、Companion 与 Reason 模式会改变提示策略和交互重点；聊天与长期记忆保存在本机 SQLite 中，并可在隐私与数据中心导出或清除。

Athena 默认连接用户自己安装的 Ollama 和兼容本地模型。部分语音与实验性研究功能可能连接第三方服务，必须单独说明并取得同意；因此不得宣传为“所有功能完全离线”。

Execute 是独立的 Beta 工作区，默认关闭。启用后可以在明确权限和逐次高风险确认下执行文件、终端或网络操作。它不属于普通聊天的默认能力，用户可以随时降权或停止后续步骤。

## 系统与依赖

- Windows 10/11 x64；精确最低 build、内存和磁盘要求仍需真实设备矩阵确认。
- 用户需自备兼容版本的 Ollama 和本地模型；轻量安装器不包含模型。
- 离线包只有在模型、Ollama 与全部再分发许可复核通过后才会提供。
