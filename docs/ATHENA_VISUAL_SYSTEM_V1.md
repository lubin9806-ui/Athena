# Athena 主视觉、UI 与 IP 系统 V1

状态：`Historical exploration / Superseded`

> 2026-09-08 更新：本稿将苏时夏作为主 IP 的假设已被用户明确修正。当前以 [产品内核](brand/PRODUCT_FOUNDATION.md) 和 [统一视觉规范](brand/VISUAL_SYSTEM.md) 为准：Athena 是独立品牌角色，苏时夏保留为独立人格。下文与旧母版图保留作历史探索，不再作为实施依据；三角 A 与禁止全部希腊符号的规则亦未获确认。

本版不是最终美术交付，而是三套系统共用的母版。它把 Athena 的品牌识别、桌面 UI 和苏时夏 IP 统一到同一个视觉语言里，作为后续界面改造、Live2D 生产、商店素材与宣传图的唯一上游方向。

## 一句话定义

**安静、可靠、近在手边的本地智能陪伴。**

主视觉隐喻是“日光穿过矿物玻璃”：不是炫技式透明，也不是冷冰冰的 AI 控制台，而是有厚度、有自然光、有微弱材质感的现代桌面空间。

## 1. 主视觉系统

### 核心识别

- 主符号：经过切角与负形处理的三角 `A / path` 标记。
- 重复触点：应用图标、苏时夏发夹、发送按钮、焦点状态、启动画面与商店封面。
- 使用原则：每个画面只允许一个主标记成为视觉焦点，其余位置只做低调呼应。
- 禁止：神庙、立柱、桂冠、猫头鹰、希腊回纹等字面化“雅典”符号。

### 色彩母版

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Warm stone | `#F1EDE4` | 日间主背景、品牌画布 |
| Paper ivory | `#FAF8F3` | 高层级阅读面、输入区高光 |
| Graphite | `#25302D` | 主文字、图标、深色标记 |
| Mist sage | `#BFCBC3` | 大面积环境色、非交互层 |
| Mineral green | `#477A64` | 品牌焦点、执行动作、在线状态 |
| Muted rose | `#B98783` | 陪伴温度、苏时夏身份色 |
| Night graphite | `#0E1A20` | 夜间背景基色 |

规则：界面以中性色为主，单个状态只出现一个功能强调色；陪伴模式的玫瑰色不能和绿色同时抢夺主操作。

### 材质

- 主背景：暖石/纸张，带极轻微矿物颗粒，不使用平坦纯白。
- 控件：局部日光玻璃，只用于标题栏、模式切换、输入框和浮层。
- 内容：开放排版或近乎不透明的阅读面，避免把每条消息塞进玻璃卡片。
- 光源：左上方自然窗光；所有高光、内阴影和投影必须服从同一方向。

## 2. UI 系统

### 当前问题

1. 日间界面整体偏白，背景、消息区和控件的明度距离太小，视觉层级被冲淡。
2. 主聊天区缺少稳定的品牌/IP 锚点，空状态容易显得空而不是“安静”。
3. 当前样式文件叠加了多代 token 与覆盖层，颜色语义已出现漂移，后续改动容易互相覆盖。
4. 模式色较多，但主品牌色不够稳定；用户看到的是四种模式，而不是一个 Athena。
5. 苏时夏在独立美术资产中较完整，在主产品体验里露出不足，UI 与 IP 仍像两条平行线。

### 组件原则

- 标题栏：品牌名、苏时夏状态与系统入口组成单一水平层；不再依赖大块白色外框。
- 模式切换：品牌中性底 + 单一移动选中面；模式色只影响选中面、发送按钮和少量内容提示。
- 空状态：左侧对话文案，右侧或背景边缘出现低干扰苏时夏半身陪伴层；在窄窗中自动退为头像/状态标。
- 消息区：助手内容优先开放排版；长内容进入柔和阅读面；用户消息保持较小、较实的气泡。
- 输入框：保持全屏最强触感，但降低整体发光；聚焦只在输入区域产生 2–3 px 抬升和局部高光。
- 侧栏与设置：采用相同的 4pt 间距、圆角和层级 token，不再独立发明材质。

### Token 结构

第一轮代码改造应将散落 token 收束为五层：

1. `brand`：固定品牌色与字色。
2. `theme`：day/night 背景与表面映射。
3. `mode`：create/companion/reason/execute 的局部强调映射。
4. `material`：stone/paper/glass/reading-surface。
5. `component`：composer/mode-switch/titlebar/panel/message。

组件不得直接写品牌十六进制色；只消费语义 token。

## 3. IP 系统：苏时夏

### 核心形象

- 明确为成年年轻专业人士，气质温和、清醒、可靠，不做校园制服化或幼态化。
- 保留：肩长黑发、克制表情、白衬衫、深色下装、三角发夹。
- 提升：服装面料层次、发丝轮廓、眼神光、手部姿态与坐姿/半身工作姿态。
- 三角发夹升级为品牌共用识别点，但不能像硬贴 Logo。

### 产品内露出层级

1. `Presence mark`：标题栏小头像/发夹标 + 在线、倾听、思考、说话状态。
2. `Companion portrait`：空状态与陪伴模式的半身构图，响应窗口宽度。
3. `Live layer`：Live2D/分层 2D 的呼吸、眨眼、视线、口型与低幅度姿态。
4. `Hero art`：启动页、商店图、官网与宣传画面的完整主视觉。

### 动作基线

- 待机：呼吸、眨眼、极小幅视线移动。
- 倾听：身体略前倾、视线集中，避免夸张循环。
- 思考：短暂停顿与一次眼神偏移，不使用持续转圈。
- 说话：口型、轻微头部节奏与句末回落。
- 完成：微笑或轻点头一次，不使用庆祝粒子。

Live2D 仍需经过真实 Cubism 绑定与 `.moc3` 导出后才能称为正式 Cubism 模型；分层 2D 运行时可以作为中间产品，但必须如实标注。

## 4. 第一实施阶段

### Slice A — 视觉基线

- 建立唯一的 V1 token 源。
- 把日间背景从泛白改为暖石与纸张层级。
- 将品牌主焦点统一到矿物绿；陪伴玫瑰只做语义温度。
- 新增三角 `A` 品牌标记的矢量源与 app/titlebar 规格。

### Slice B — 主聊天屏

- 重做空状态构图与文字层级。
- 加入苏时夏的响应式陪伴位置。
- 收束标题栏、模式切换、消息区和输入框材质。
- 完成 480×700、1280×800、1920×1080 三档视觉检查。

### Slice C — IP 生产包

- 冻结正面与三分之二侧脸的最终脸型、发型和发夹。
- 输出头肩、半身、全身三种产品构图。
- 在正式 Cubism 前先完成分层、透明边缘、表情与动作检查表。

## 5. 验收门槛

- 第一眼能同时识别 Athena、苏时夏和日光矿物玻璃，而不是普通浅色聊天软件。
- 日间模式文字、控件和背景有明确三层以上对比，不再发白。
- IP 出现时不遮挡阅读、输入与窗口控制；窄窗仍可用。
- day/night 与四种模式属于同一品牌，不出现八套互相竞争的皮肤。
- 动效只由启动、交互、真实语音/模型状态触发；空闲时不持续占用 GPU。
- 通过键盘焦点、减少动态效果、缩放与常见窗口尺寸检查。
- 任何“正式 Live2D/Cubism”交付必须附真实运行与包内容证据。
