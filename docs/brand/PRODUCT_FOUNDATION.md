# Athena 产品内核与品牌起点

状态：工作稿 v0.1 · 2026-09-08。用户确认的起点是希腊神话中的智慧女神雅典娜、本地 AI 助手，以及「一个独属于自己的智慧女神」。其余内容为本轮补充的产品与品牌提案，不代表全部能力已实现。

## 产品背景

Athena 的灵感来自希腊神话中的雅典娜——智慧的象征。

进入 AI 时代，知识和答案变得更容易获取，但每个人仍然需要面对自己的问题：如何理解复杂的信息，如何看清选择之间的取舍，如何把模糊的想法变成清晰的判断，又如何让一个尚未成熟的念头逐渐成为完整的作品。

Athena 因此诞生。我们希望把「智慧女神」的意象带入个人电脑，创造一个以本地为基础、由用户自主掌握、能够长期相伴的 AI 助手。她从你的问题出发，帮助你梳理思路、发现遗漏、比较可能性，在一次次交流与共同完成的事情中，逐步形成与你相适应的协作方式。

「独属于自己」意味着你可以选择她的交互方式、使用的模型、允许保留的记忆，以及能够参与的工作范围。她对你的了解应当建立在知情与可控之上，让个人化来自长期积累，也允许你随时修改、删除或重新开始。

Athena 所承载的智慧，是理解问题、辨析信息、承认不确定性，以及在需要时提出不同意见的能力。她应当既能温和地听你表达，也能认真地与你推敲；既能帮助你展开想象，也能协助你检查想法是否成立。

我们的愿景，是让每个人都能拥有一位属于自己的智慧伙伴：在困惑时帮助你厘清问题，在创作时与你共同完善想法，在行动前帮助你看清方向。最终，让你更有能力思考、创造和作出自己的选择。

## 一句话定位

Athena 是一个以本地为基础的个人 AI 助手，也是独属于你的智慧伙伴，与你一起思考、完善想法，并在授权范围内协助行动。

## 核心品牌表达

- 品牌主张：独属于你的智慧女神。
- 产品解释：与你一起思考，让想法逐渐完整。
- 对外短介绍：灵感源于智慧女神雅典娜，Athena 将 AI 带入你的个人电脑。她从你的问题出发，陪你梳理思路、推敲判断、完善创作，让日常积累成为更适合你的智慧支持。
- 长期愿景：让每个人拥有自主掌握、能够长期积累的个人智能伙伴。

## 产品体验结构

沿用当前界面的两个顶层空间：

- **陪伴**：自然表达、整理感受、延续话题。智慧表现为认真倾听、理解语境、在合适的时候帮助用户看清问题。
- **创作**：围绕目标展开工作，包含创作、推理、执行三种方式。创作帮助表达与形成作品；推理帮助分析与核验；执行在用户授权范围内调用工具。

两个空间共享品牌身份，分别承担明确的体验。视觉统一不应抹平它们的行为边界。

## 品牌角色与独立人格

用户已确认：Athena 建立独立品牌角色，苏时夏保留为独立人格。

Athena 代表产品的智慧、判断力与守护感，是默认品牌身份。苏时夏具有自己的角色身份和表达方式，不应直接替代为 Athena 的品牌形象。使用某个人格时，界面应清楚显示当前身份，保留稳定的 Athena 产品标识。

Athena 的人格基调建议为：温和而清醒，聪明且有耐心，有判断力，也愿意承认未知。「属于你」体现为个人化与自主权，不要求盲目迎合；「女神」提供文化意象和角色辨识度，不构成全知、永不出错或替用户作决定的承诺。

## 对视觉系统的约束

主视觉、UI 与 IP 围绕同一条关系展开：文化起点是雅典娜，产品价值是个人智慧支持，体验感受是清晰、从容、可信与亲近。

- **主视觉**：用光、材质、留白与有秩序的构图表达思考逐渐清晰的过程。神话元素应有明确含义，先探索再决定是否采用，不能仅凭名称堆叠古典装饰。
- **UI**：以内容可读性和推敲问题的效率为先。延续已有日光／夜色方向，控制层可使用克制玻璃材质，正文阅读区域保持安静。具体配色与排版待设计基线评审。
- **IP**：探索智慧女神在当代个人 AI 中的形象。以成年、可信、亲近且有主见为角色气质，研究如何用轮廓和少量标志性细节建立辨识度。第一张人物探索不能视为最终角色设定。

## 对外表述与实现边界

当前仓库 README 标记为 Desktop 0.9 Private Beta candidate（0.9.7-beta.1）。发布文案应分别说明已经验证的能力与长期愿景。

「本地优先」不等于所有功能离线可用：仓库支持本地模型和可选远程模型，联网搜索等功能仍涉及网络。对外避免「全部数据永不离开设备」「完全离线完成所有任务」「无限记忆」「永远理解你」等未经验证的绝对表述。

`src/shared/releaseFeatures.ts` 当前保持 `live2d: false`。品牌人物概念图属于设计资产，不代表分层原画、Cubism 工程或已启用的桌面角色能力。
