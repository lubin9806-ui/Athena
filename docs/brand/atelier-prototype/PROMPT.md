# Main visual reference

Built-in image generation; use case ui-mockup. Generated before implementation.

Use case: ui-mockup. Generate ONE high fidelity, implementation-ready desktop application screen, landscape 16:10, for Athena, a personal AI thinking companion. This is an actual software interface, NOT a marketing landing page, NOT a dashboard, NOT a moodboard. The user wants a novel, playful but adult and elegant interaction replacing sidebar+chat. Concept: an open personal thinking desk; the user can pick up, arrange, connect, unfold and progress thought objects. No sidebar, no chat bubbles on home, no traditional top-level Companion/Create/Reason/Execute tabs.

Brand: warm ivory #F5F1E8 background, muted sage #53675F, graphite #222C2A, subtle cream and very small pale apricot notes. No purple, blue neon, avatars, faces, IP characters, figurines, mascots or helmets. Top left small Athena wordmark in refined serif (this is the approved existing brand style), optional tiny monochrome crescent-temple-feather mark, never invent a new A logo. Font for Chinese app text is a clean contemporary Chinese sans, dark and readable.

Layout precisely: slim open header with Athena at left, small centered label '随心桌面', search, theme and settings at far right. No full-width header border. Beneath at upper-left a modest 32px two-line greeting '今天，想从哪里开始？' and muted smaller text '把念头放下来，再一起慢慢展开。'; this is app welcome text, not giant hero. A small '整理桌面' text button near upper right of work surface. Most of the window is an airy off-grid spatial canvas with just FIVE thoughtfully positioned functional thought objects; lots of usable negative space, no outer wrapper panel.

1. Upper-left of canvas a small ivory paper note rotated -4 degrees titled '一个还没想好的念头' with a short '给下一个小项目，留一点空间。' and a tiny folded corner.
2. Central primary focal point: a larger sage-green rounded tactile thought card tilted +2 degrees, about 330x220 px in a 1440px screen. White text title '把这一周，过得松一点', smaller '先为自己留出一个下午。'. Bottom small '打开这个想法' and a round arrow control. Gentle realistic shadow and soft glass-edge accent, not shiny plastic.
3. Upper-right a vertical pearl frosted-glass prompt note, 245x240px, title '换个角度', text '如果今天只做一件事，什么会让你轻松一点？', rounded '一起展开' button.
4. Lower-left a compact pale apricot capsule note titled '今天有点累', small line '先聊聊，不急着解决。'.
5. Lower middle-right a white reference slip '读到的一句话' then '不必完整，也值得开始。', small bookmark.
Use only TWO very fine quiet curved connector lines showing meaningful relationship between central thought and prompt/reference, not a decorative network or technical grid.
Centered at bottom a floating horizontally oriented pearl liquid-glass tool dock with clearly labeled buttons '+ 记个念头', '连一连', '一起聊', '收纳' and small search keyboard shortcut 'Ctrl K'. 68px high, subtle inset rim highlights and refractive edges, readable text. The dock has a soft oblong silhouette with generous target spacing; not an OS dock full of app icons. Bottom-left tiny unobtrusive '交互探索 · 本页示例' as honest prototype labeling.

Lighting: soft daylight, restrained surface depth, glass only dock and pearl note. Coherent white/sage/graphite, quiet warmth and playful physicality. No huge background circles, no decorative real temple, no ornamental Greek columns, no stock photos, no random blobs. Not a 3D perspective render: straight-on UI screenshot with slight rotations only of individual thought objects. Draw every label legibly, sufficient 14-16px body. Deliver one complete screen with all controls inside frame and comfortable laptop proportions.
