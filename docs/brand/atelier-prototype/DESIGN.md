# Athena · 随心桌面

## 本轮决定

用户明确要求不保留原有操作逻辑。新原型以想法对象为中心，取代左侧历史导航、固定聊天主场和模式切换；旧样板保持不变，真实产品仍未迁移。

核心路径：记个念头 → 点击展开 → 连接另一条线索 → 留下一步。陪伴按需打开，不默认把每件事都变成任务。

## 画面读取

主参考 `reference-desk.png` 由内置图像生成工具先行生成。单张完整应用画面，非营销页面。

- 画面优先级：中央灰绿想法 > 左右纸片线索 > 浮动工具带。没有外层大卡片、侧栏或统计面板。
- 顶栏无横向分隔线，品牌左置，桌面位置居中，搜索、主题、设置靠右。品牌继续使用已确认 SVG，不采用生成图里简化变形的标志。
- 欢迎语左置约 32px，分为两行；正文 14–16px，纸片标题 20–25px，主想法标题 28–32px。英文 Athena 延续已有衬线字标，其余为中文系统无衬线字体。
- 桌面只保留五个明确可操作对象：左上念头、中央主题、右上问题、左下感受、右下摘录。旋转约 -4 到 +3 度，温和投影表现可拾起的层次。
- 主想法约 390×250px，纸片约 260×185px，问题约 250×240px。长内容进入聚焦面板，桌面上不堆放全文。
- 两条曲线表示实际关联，节点中心随移动更新。不是装饰性网络，关联可查看和删除。
- 浮动工具带底部居中，主要入口有中文标签；玻璃用于工具带、问题片和浮层。文字与点击区域不发生光学变形。
- 灰绿 `#53675F`、暖白 `#F5F1E8`、石墨 `#222C2A`，浅杏只区分感受纸片。夜色使用同一色相体系。
- 生成图的边角植物、叶纹和重颗粒不是必要交互，代码不额外加入这些装饰；纸片折角和书签用确定性 CSS 表现，不把整幅图片当网页。

## 交互与边界

- 桌面有限、可整理，不做需要缩放导航的无限画布。触屏窄屏切换为同一数据的纵向想法流。
- 拖动仅是快捷方式；点击展开、选择目标连线、方向键移动均有可见入口与说明。
- 聚焦后可直接改标题与内容；关闭回到来源卡。下一步为可编辑、可撤回的示例计划，不执行电脑操作。
- 收纳可以恢复；所有示例、编辑与关系仅留在本页，刷新清空。不访问真实模型、配置、文件、数据库或设备。
- 陪伴对话独立按需打开，预设内容明确标注，不自动转成计划。
- 动效表达拾起、归位、聚焦和关联，静止时不持续渲染；减少动效和实色表面独立可选。

## 设计流程

使用 image-to-code / imagegen 的先画面、后分析、再实现流程；不使用 design-taste-frontend 的营销页版式规则，因为本任务是应用交互界面。
