## 交互

从念头出发，不以固定侧栏或旧模式标签作为主要入口：

- 记个念头：写标题与片段，点开继续编辑；长内容在卡片中折叠，详情保留全文。
- 摆放：宽屏拖动移动柄，或用方向键移动，Shift 加速；Escape 取消拖动，整理桌面恢复摆放。
- 连一连：依次点选两条想法；支持键盘，不必精准拖线。重复关系不会叠加，可在详情里断开。
- 展开：保留一个示例追问，也可留下可编辑、可勾选、可撤回的三步草稿。
- 一起聊：以当前想法开场，或不带任务聊天；仅预设回复，支持停止和中文输入法保护。
- 收纳：收起想法但保留关联，之后取回；全空桌面也有明确入口。
- 搜索：Ctrl / Cmd + K；查标题、片段和动作，方向键与 Enter 选择，Escape 返回。

宽屏使用自由摆放；1100px 以下改为两列阅读，760px 以下为单列。窄屏不展示误导性的拖动柄或被截断的连线，关联仍可在详情里查看、增删。

## 材质与动效

暖白、灰绿、少量柔杏色。纸片、主想法和局部玻璃各有材质，玻璃集中在工具坞和辅助区域，不扭曲文字。日光 / 夜色是该方案内部明暗选择。

指针高光按事件更新，拖放和弹窗动效有限时长，无持续空闲动画。支持实色开关、减少动效、系统减少透明度和高对比度降级。这是网页玻璃近似实现，不是原生 Liquid Glass。

按 image-to-code 先生成独立参考画面，再提取布局并实现原生 HTML/CSS/JS。参考图中的自动生成 Logo 没有采用，实际页面共用已定资产。参见 [DESIGN.md](DESIGN.md)、[PROMPT.md](PROMPT.md)。

## 验证

运行隔离离屏测试，不启动正式 Athena，不读取真实设置或数据库：

```powershell
$athenaQa = Start-Process -FilePath 'G:\Athena\node_modules\electron\dist\electron.exe' -ArgumentList 'G:\Athena\docs\brand\atelier-prototype\verify.cjs' -WindowStyle Hidden -PassThru -Wait
$athenaQa.ExitCode
```

结果见 [qa-report.json](evidence/qa-report.json)，真实渲染截图位于 `evidence/`。覆盖四种窗口尺寸、日夜外观、编辑、连线、原生指针拖动、收纳、搜索、IME、焦点恢复、实色与减少动效，以及品牌文件哈希不变。

## 范围边界

这里只实现独立原型与主题入口设计。数据在当前页面暂存，刷新会恢复示例；示例聊天重新展开时重置。自由桌面不是无限画布，大量对象的自动整理仍需后续设计。

没有接入真实模型、记忆、人格、工具权限或系统操作；没有改正式软件默认配置、数据库、安装包。两个原型暂不共享状态，采用新标签打开以保留已有临时页面。

正式接入约定见 [THEME_PRESETS.md](../THEME_PRESETS.md)：日光默认，经典和随心桌面可选；共用业务状态和品牌资产，不能因切换丢失草稿或改变权限。
