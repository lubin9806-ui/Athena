# Athena UI / AI Visual Board 01 Prompt

## Use case

High-fidelity product UI system board for the Athena Windows desktop application.

## Direction

Create one polished landscape UI/AI visual design board for the Windows desktop application Athena, based on the current product screenshots and the approved Athena identity. This is a product interface system presentation, not a website and not a brand moodboard.

Athena is a local personal AI companion inspired by the Greek goddess of wisdom. It helps the user think, create, reason and execute. The feeling is calm intelligence, gentle companionship, privacy, clarity and quiet confidence. Do not include a character illustration, anime girl, avatar, face or mascot inside the interface.

Use the approved Athena mark only as a small product identity at the top left. Do not scatter temple, columns, feathers, crescents or stars as decorative icons. Outside the logo, translate the identity only into abstract rhythm: one faint cropped open arc, subtle vertical order and at most one soft curved gesture.

## Required board content

- One dominant Companion-mode desktop screen.
- One smaller Execute-mode workspace.
- One compact strip specifying fourteen functional icons.
- Top bar with product, local model status, conversation, Project, memory, settings and window controls.
- Primary navigation for 陪伴 and 创作.
- Work modes 创作, 推理 and 执行.
- Sidebar with 新对话, 临时聊天, Project, Project 指令 and conversation history.
- Companion empty-state copy: 在这里，想法可以慢慢成形。
- Supporting copy: 创作、整理、推理，或者只是说两句。
- Prompt chips: 聊聊今天, 整理一下心情, 继续上次的话题.
- Composer with plus, attachment, web, tools, microphone and send.
- Execute panels for 当前 Project, 当前任务, 计划, 执行记录 and 结果.
- Permission control for 关闭, 只读, 文件 and 完全.
- Functional icons: sidebar, new chat, temporary chat, project, file, web, tools, microphone, send, memory, settings, pin, refresh and close.

## Visual system

- Warm Ivory `#F5F1E8`
- Surface `#FCFCF8`
- Athena Sage `#53675F`
- Graphite `#222C2A`
- Muted Gray Green `#66716C`
- Champagne `#B49A6A`, under five percent
- Panel radius 16px, control radius 10px, composer radius 24px
- Fine dividers, restrained localized shadows, mostly flat materials
- Consistent rounded line icons on a 24px grid with approximately 1.75px stroke
- No purple, blue AI gradients, neon, glossy 3D icons, literal Greek scenery, fake analytics or glass overload
- No IP character anywhere
