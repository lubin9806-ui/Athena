# Athena 统一视觉规范

2026-09-08 · V0.2 评审基线。用户已确认主 IP 仍是雅典娜，但重新设计女神形象，风格更偏二次元；原现代知识工作者形象暂停。配色、字体、材质及具体外形是本轮设计提案。本文取代 `docs/ATHENA_VISUAL_SYSTEM_V1.md` 的实施地位。

用户另已明确两条边界：**界面视觉里不放 IP 形象**，角色只出现在品牌与宣传物料；**Athena 主图标方向已确认**，以月弧、神殿、羽毛与双星构成产品识别，字标使用首字母大写的 `Athena`。桌面应用的接入情况见文末「评审页与实施范围」。

## 共同方向

**当代的个人智慧女神：清醒、从容、亲近、有判断力。**

把文化来源转化为视觉秩序与可识别的细节：清晰的阅读层级代表理性；稳定的布局代表可靠；局部透光与温和的材质代表亲近；人物神态与独有配饰承载 Athena 的角色身份。

主视觉、UI、IP 共用颜色、材质与轮廓语言，各自承担不同工作。主视觉负责记忆点，UI 负责使用效率，IP 负责人格与情感识别。

## 色彩：一套品牌，两种光照

可复用值以同目录 `visual-tokens.css` 为准，评审页直接引用。数值为设计目标；对比度结果见 `visual-qa.json`。

| 语义 token | 日光 | 夜色 | 用途 |
| --- | --- | --- | --- |
| sunken | #E7E4DA | #121815 | 内容之下的页面底，让阅读面有东西可浮 |
| bg | #F2F1EC | #18201D | 背景 |
| surface | #FCFCF8 | #222D27 | 阅读、表单、浮层 |
| surface-soft | #E6E9E2 | #2D3A32 | 选中底、用户消息、次级区域 |
| text | #222C2A | #EDF1EC | 主要文字与图标 |
| muted | #58645F | #B4C0B7 | 次级说明与输入占位文字 |
| accent | #3E6855 | #B4CDBB | 主按钮、选中标记、链接与焦点 |
| on-accent | #FFFFFF | #18201D | 主按钮文字 |
| silver | #A6ADA7 | #A6ADA7 | 装饰线与人物金属细节，不用于小字 |
| danger | #9B403F | #F0AAA5 | 错误与危险操作，同时给出文字 |

2026-09-10 增加 `sunken`。原来日光的三层彼此只差几个百分点，卡片浮在几乎相同的底色上，正是本文
「当前问题」第一条说的发白、层级被冲淡。新层只是加在最下面，**没有改动任何既有色值**，因此
`visual-qa.json` 里的对比度结论仍然成立——更深的底只会让深色文字更好读。

每屏以中性色为主。矿物绿是交互强调色，银色是低频材质色。陪伴、创作、推理、执行使用相同主按钮色，以位置、标签和选中面区别状态。功能反馈始终带文字，不只靠颜色。

## 字体与排版

- 品牌主标题：中文 Noto Serif SC / Source Han Serif SC，英文 Georgia；正式字标需单独定制与小尺寸验证。
- 产品 UI：Segoe UI Variable / Microsoft YaHei UI，优先本机可用字体；代码和数据用 Cascadia Code / Consolas。
- 日常正文 15px / 1.75；消息可达 16px / 1.8；控件 14px / 1.4；辅助文字 12px / 1.5；禁止用辅助字号承载正文。
- 宣传主标题 48–72px；产品空状态标题 28–36px，避免把大标题用在所有面板。
- 中文长文以约 36–42 字宽为起点，用户可缩放；预览采用 `max-width: 42em`。
- 中文字体若未安装，允许系统后备；正式宣传导出前需确认字体和排版，字体替换不得导致裁切。

## 形状、材质与图像

- 空间使用 4px 基础尺度：4、8、12、16、24、32、48、64。普通操作高度至少 40px，密集桌面控件不低于 32px。
- 普通控件圆角 10px、面板 18px、输入框 24px；药丸形仅用于模式分段与身份头像等明确用途。
- 主内容使用稳定、清楚的实色阅读面。矿物颗粒只在宣传或内容外缘轻量出现，不铺在长文和输入文字背后。
- 玻璃只用于控制层；预览以高不透明度半透明表面模拟，提供不透明后备。它不是官方原生 Apple Liquid Glass。
- 宣传图统一自然侧光、克制银色与象牙白、低饱和背景。UI 的夜色通过语义 token 对应，禁止简单反色。
- 图标保留项目当前线性语法，24px 网格、约 1.7px 线宽。先统一规格，不为了风格替换整个图标库。

## 品牌符号与神话来源

主图标方向于 2026-09-08 确认：开放月弧围合中央希腊神殿，右下羽毛向上舒展，双星作为低频细节。它共同表达雅典娜的文化来源、智慧秩序与个人陪伴的柔和感。该组合是 Athena 的当代品牌叙事，不作为古代历史符号学的断言。

概念方向已锁定，但位图不是生产母版。正式替换软件资源前，需按源图制作统一矢量路径，分别导出纯图形与字标组合，并校准 16/24/32/48/256px；小尺寸允许减少羽毛内线和星芒，但不得改变月弧、神殿与羽毛的主要轮廓关系。

## UI 组件与状态

| 组件 | 共用规则 |
| --- | --- |
| 顶栏 | 产品标识稳定；当前人格单独标注；连接信息来自真实系统状态 |
| 空间导航 | 顶层「陪伴／创作」；创作下含「创作／推理／执行」 |
| 消息 | 助手开放排版；用户消息使用柔和实色底；长内容保留可读宽度 |
| 输入框 | 一个主要提交动作；空内容不可提交；等待、停止、错误在原处反馈 |
| 设置面板 | 和输入区共享背景、字号、间距与焦点样式；减少独立皮肤 |
| 人格展示 | 产品品牌与当前人格可同时辨识；窄窗退为名字与头像；不遮挡阅读 |

状态词必须具体：未连接、正在处理、已完成、连接失败。演示页的状态明确为示例，不表示真实模型请求。品牌角色不承担系统在线状态的唯一表达。

## 动效

120ms 用于 hover 与按压，220ms 用于颜色和菜单过渡，360ms 用于抽屉。曲线统一为 `cubic-bezier(.2,.75,.2,1)`，普通位移不超过 4px。空闲画面静止，实际工作状态才允许局部动效。

减少动态效果时取消位移、缩放和循环；键盘焦点用 2px 清晰实线，不依赖柔光。所有动画都需可以打断。

## IP 美术方向

用户确认：仍是雅典娜，重新设计女神形象，做得更二次元。美术采用清晰动漫线稿、赛璐璐层次、可读表情和稳定轮廓；保留智慧、清醒、亲近、有判断力的气质。初稿探索银白长发、灰绿眼睛、橄榄叶形银饰与绿色小石、象牙白古典垂褶和石墨灰裙装。具体造型尚待用户审看，不视为已批准脸型或服装。角色更二次元不意味着界面加入游戏 HUD 或装饰性魔法效果。

`athena-character-study-01.png` 是已暂停的早期人物探索，本版评审页不再展示或沿用。苏时夏保留独立人格；最终主 IP 与其关系随用户新方向补充。

发布版 `live2d: false` 保持现状。静态概念、分层原画、参数绑定和正式 Cubism 模型是不同交付物。
