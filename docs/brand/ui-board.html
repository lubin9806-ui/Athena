这一版改了什么

把背景从灰绿的照片材质换成象牙白实色，玻璃只留在标题栏、导航和输入框；正文区域一律安静。

  • 一个强调色四种模式共用矿物绿，靠位置和选中面区分，不再是四套皮肤
  • 界面不放角色空状态是排版，不是形象；角色只留在品牌与宣传物料
  • 折叠侧栏只留两件事新对话和临时聊天，其余等展开；84px 下不再露出半截控件
  • 标志是临时的标题栏里那个 A 是占位，等主视觉定稿后替换
