# Athena UI / AI 视觉系统 V1

## 状态

- 性质：高保真视觉方向稿，尚未写入产品代码。
- 视觉稿：`athena-ui-ai-visual-board-01.png`
- 依据：当前产品真实操作逻辑、已确认 Athena 标志与主视觉系统。
- 边界：IP 人物不进入软件界面。

## 核心判断

Athena 的界面不是“神话主题皮肤”，而是一个温和、清晰、可信的个人智慧空间。希腊故事与 Athena 名称的叙事由品牌标志承担；产品界面只继承秩序、开放与流动三种抽象感受。

## 操作结构

### 一级空间

- 陪伴：低压力交流、情绪整理、持续对话。
- 创作：进入面向产出的工作空间。

### 创作子模式

- 创作：组织素材、扩写方向、形成初稿。
- 推理：拆解假设、比较方案、检查遗漏。
- 执行：唯一可以调用电脑工具的工作区。

### 通用框架

- 顶栏：品牌、模型与本地状态、当前会话、Project、记忆、设置、窗口控制。
- 左侧栏：新对话、临时聊天、Project、Project 指令、历史对话。
- 主内容区：模式内容、空状态、对话或执行反馈。
- 底部输入区：输入、附件、联网、工具、语音、发送与状态提示。
- 右侧抽屉：记忆与设置，不与主任务抢层级。

## 视觉语言

### 色彩

- Warm Ivory：`#F5F1E8`，主背景。
- Surface：`#FCFCF8`，主要面板。
- Athena Sage：`#53675F`，品牌与核心操作。
- Graphite：`#222C2A`，主文字。
- Muted Gray Green：`#66716C`，辅助文字。
- Champagne：`#B49A6A`，小于 5%，仅用于微小状态或焦点提示。

### 形态

- 面板圆角：16px。
- 控件圆角：10px。
- 输入框圆角：24px。
- 分隔线：1px，低对比灰绿色。
- 阴影：只用于输入区、浮层和当前任务，范围克制。
- 透明材质：仅用于局部控件，不作为全界面效果。

### 品牌元素使用

- 完整标志只出现在产品身份位置。
- 空状态最多出现一条极淡、被裁切的开放弧线。
- 不把神殿、柱式、羽毛、月弧或星芒重复做成背景装饰。
- 不使用紫蓝 AI 渐变、霓虹、魔法光效或 3D 金属图标。

## 软件内图标

统一采用 24px 网格、约 1.75px 描边、圆角端点与简洁轮廓。图标首先服务识别，不承载完整品牌故事。

## 界面气质分配

- 陪伴界面：留白更多、提示更柔和、输入区更有包裹感。
- 创作与推理：信息密度适中，强调结构与连续工作。
- 执行界面：面板更明确，任务、计划、记录、结果和权限必须可扫描。
- 所有模式共用同一套颜色、图标、圆角和文字层级，避免像四个不同产品。

## 实现提醒

- 本视觉稿用于确定系统方向，不作为像素级开发验收图。
- 生成图中的小字号文本需要在真实组件中重新排版。
- 已确认品牌标志仍需制作生产级 SVG 与小尺寸校准稿。
- 实现图标时应采用一套完整图标库或一套统一绘制规范，不混搭不同线宽和端点风格。
