# Athena · 布局、动效与材质

本轮作用于独立交互样板，不改真实 renderer、配置、人格、聊天记录或模型连接。

## 布局

- 桌面侧栏 252px，中等窗口 224px；720px 以下使用覆盖式侧栏，并使被覆盖的主内容不可交互。侧栏收起后释放阅读宽度。
- 阅读区域最大 810px，输入区域最大 840px。宽屏增加留白，不无限拉长正文。
- 陪伴 / 创作是第一层，创作 / 推理 / 执行是第二层。两级导航上下排列，预留第二行空间，切换不挤动第一层标签。
- 输入区域固定在主视图底部，正文独立滚动。多行输入有高度上限，元信息保留在输入区域内。
- 加号菜单独立定位在输入框上方，保留 12px 目标间距。记忆、设置与工具抽屉互斥。
- 阅读旧消息时保留滚动位置；新回复不会强行拉到底部，可通过“回到最新消息”继续阅读。

## 动效语言

| 场景 | 处理 | 时长 |
| --- | --- | --- |
| 点击 / 按压 | 小幅下沉、发送按钮轻压，不改变点击区域 | 140ms |
| 一级 / 二级选中 | 单一选中底板平移 | 300 / 220ms |
| 侧栏让位 | 侧栏平移；阅读区、导航、输入区位置补间，不缩放文字 | 300ms |
| 内容模式切换 | 5px 内轻移与淡入 | 220ms |
| 新消息 / 回复完成 | 仅新增或被替换的消息轻移淡入，保留旧 DOM | 220ms |
| 工具菜单 | 向下归位 6px 与淡入；退出立即取消焦点和命中 | 180 / 140ms |
| 抽屉 | 固定右边缘，遮罩式展开与淡入，文字不拉伸 | 280 / 140ms |
| 日光 / 夜色 | 表面、文字、边界颜色过渡 | 220ms |

使用 `cubic-bezier(.2,.8,.2,1)`，不加入持续摇摆、呼吸光或背景漂移。布局先一次性计算最终几何，再用 transform 补间位置；不逐帧改变侧栏宽度。

浮层关闭的第一帧即 `inert` 且退出可访问树，视觉退出结束后隐藏。快速重复开关会取消旧动画，不遗留遮罩或隐藏焦点。系统或用户减少动效生效时，正在运行的 JS 动画也会结束，而不只停掉 CSS 动画。

## 液态玻璃

这是一套**网页液态玻璃近似**，不是系统原生材质，也不声称物理折射实时文字。

- 实际 `backdrop-filter` 模糊底层颜色，配合柔和内边缘、轻微投影、局部透光和指针高光。
- 输入框保留 80% 日间 / 84% 夜间实体底色；菜单 91% / 94%，抽屉 96% / 97%。信息越密，透明度越低。
- 高光只影响装饰层；字形、输入光标与点击区域不跟随指针变形。
- 连续指针事件合并到单个动画帧；没有空闲 RAF 循环。退出、页面失焦和隐藏面板时清理按压状态。
- 用户关闭玻璃、系统减少透明度、强制颜色或不支持模糊时，使用完全不透明表面并移除 backdrop-filter。
- 减少动效时仍可保留静态玻璃，禁用指针跟随。可在“设置 → 外观与动效”分别关闭玻璃或动效。

## 验收边界

自动化检查验证事件、几何、计算样式、回退、滚动与动画生命周期；截图用于检查字体、留白、层次和可读性。计算对比度是均匀底色近似，不能代表所有高光像素的精确对比度。

仍需在正式 Electron 集成后检查真实窗口拖动、系统缩放、高刷新率与低性能设备的帧耗时。独立样板测试不等于生产性能或完整辅助技术验收。
