# Athena Desktop 1.0 隐私政策公开草案

> **未生效 / Prelaunch。** 数据事实以 `PRIVACY_AND_DATA.md` 为准。真实控制者/发行主体、公开 URL、隐私邮箱、支付与许可证处理方尚未确定，不能用占位或虚构主体发布。

Athena Desktop 以本机处理为默认：对话和长期记忆保存在用户设备上的 SQLite 中，默认模型端点是本机 Ollama。用户可以关闭历史保存、设置保留期、导出支持范围内的本机数据或一键清除。

联网搜索、在线语音识别、在线语音合成和 Execute 外部网络工具属于不同的数据路径，需要分别说明和同意。搜索词、网页请求、音频或朗读文本可能发送给对应第三方；Athena 当前没有自有账号、云同步或遥测服务，也不宣称静态加密。

未来支付提供方会处理付款、税务和退款信息；未来许可证提供方会处理许可证密钥、SKU、应用版本、设备标识和 entitlement 状态。Desktop 应用不得保存完整支付卡信息，也不得把原始许可证密钥写入本机 entitlement 存储。处理方、目的、保留期、跨境位置和用户权利入口必须在接入后补齐。

隐私请求入口由 `config/commercial.json` 的 `identity.privacyEmail` 提供，当前未配置。正式发布前需补齐真实控制者、联系地址、法定基础、地区权利、未成年人边界、第三方名单、保留期、安全措施、投诉渠道、生效日期和稳定 URL，并完成专业复核。
