# Haru Official Live2D Reference

This directory contains a copied Haru sample model from Live2D's official
Cubism Web Samples / Sample Data Collection.

- Source: https://github.com/Live2D/CubismWebSamples
- Sample collection: https://www.live2d.com/en/learn/sample/
- License family: Live2D Free Material License / sample model terms
- Terms: https://www.live2d.com/eula/live2d-sample-model-terms_en.html

Athena uses this package as an internal reference/default runtime model variant
so the Live2D companion has a genuine Cubism baseline while the original Athena
character rig is rebuilt. Haru is not an original Athena character asset.

Public distribution remains blocked until Live2D license classification,
sample-model terms, and Athena release rights are reviewed and approved.
