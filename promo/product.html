一个 SKU，边界说清楚。

Desktop 1.0 计划采用一次性个人许可证，不设 Free/Pro 分层或订阅；最多同时激活 2 台本人 Windows 设备并覆盖 1.x 更新。价格、支付与许可证平台尚未确定，尚未开放购买。

正常换机先停用旧设备；无法访问旧设备时，通过未来正式支持入口申请人工重置。
购买后 14 个自然日内可申请自愿退款，法定消费者权利优先。退款不会远程删除本机数据。

正式材料允许展示的 6 项能力。

每项能力仍需在同一签名候选 build 中通过 Universal 与 Desktop 发布门。

01

Windows 桌面应用

面向 Windows 10/11 x64，包含桌面窗口、托盘、设置与一致的版本信息。

02

三种普通模式

Create、Companion、Reason 有不同的提示策略和交互重点，不再使用旧人格命名。

03

本机 Ollama

连接用户自己安装和许可的 Ollama 与模型；不承诺云模型或自动附带模型。

04

本机长期记忆

聊天、画像、事件和项目数据留在本机，可管理、导出、设置保留期和清除。

05

隐私数据中心

分别说明本地处理与第三方联网；联网搜索、在线语音和外部网络工具分别同意。

06

Execute Beta

独立入口、默认 Off、按级授权、高风险逐次确认、参数脱敏和任务停止。

Planned，不是 1.0 卖点。

Live2D、音乐、日历、天气、跨设备同步、云账号、Steam、Mobile、macOS、Linux 和插件市场都不属于当前 Desktop 1.0 承诺。
