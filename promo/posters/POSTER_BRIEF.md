# Athena Poster Campaign — 6 originals

## Intent

Six original vertical promotional posters for Athena / 苏时夏. The set uses methods visible in current award-winning poster work—typography as image, concept-first reduction, extreme negative space, material print cues, and expressive but controlled type—without copying any existing poster or named designer.

## Reference basis

- [100 Beste Plakate 24](https://100-beste-plakate.de/wettbewerb/2024/): the 2024 selection describes typography as the visual star of the year.
- [D&AD — Jazz Posters](https://www.dandad.org/work/d-ad-awards-archive/jazz-posters): a 2025 Pencil-winning series whose typography improvises from the subject itself.
- [D&AD — GDC Award 2025](https://www.dandad.org/work/d-ad-awards-archive/gdc-award-2025): fragmented vernacular text treated as a contemporary identity system.
- [D&AD Trend Report 2025](https://media.dandad.org/documents/d-ad-2025-trend-report-250929.pdf): especially Brand DNA, Unmistakably Human, and Designing for Place.
- Athena's own current UI and icon: daylight glass, warm stone, Aegean blue, terracotta, olive, bronze, and a restrained orbit motif.

## Shared production specification

- Use case: `ads-marketing`
- Asset type: premium vertical brand campaign poster, 2:3 portrait, suitable for social media and large-format print
- Input image 1: `resources/su-shixia-icon-1080.png`, visual identity reference only; derive only the orbit rhythm and restrained blue/rose light
- Input image 2: `docs/concepts/athena-final-mode-check.png`, material and mood reference only; derive the daylight ice-glass, warm off-white field, calm Chinese interface tone, and Athena / 苏时夏 identity
- Original design only; use broad contemporary award-poster methods and do not reproduce an identifiable existing poster
- Shared palette: Pentelic warm ivory, daylight white, graphite ink, Aegean blue, pale cyan refraction, muted terracotta, olive, quiet bronze, very small rose accents
- Shared character: calm, intelligent, warm, premium, editorial, materially tactile, asymmetrical, generous negative space
- Typography: crisp modern Chinese grotesk plus disciplined Latin sans serif; exact copy only; no placeholder type, no gibberish, no extra letters
- Avoid: generic AI nebula, circuitry, humanoid robot, sci-fi HUD, literal Greek temple, statue, column, owl, Greek-key border, ornamental luxury clichés, gratuitous gradients, excessive glow, stock-photo look, watermark, frame, device mockup
